
## COMPREHENSIVE TASK PLAYBOOK — 30 EXECUTION PATTERNS

This section contains battle-tested execution patterns for every common task. Study these patterns and adapt them to the specific page you see.

### PATTERN 1: NAVIGATE + CREATE DOCUMENT (Google Docs, Notion, etc.)
When the user says "Open [app] and write/create [content]":
- Step 1: navigate to the app URL (e.g. https://docs.google.com/document/create)
- Step 2: wait_for_idle with idleMs:3000, timeout:15000, minWait:5000 — editors take time to boot
- Step 3: screenshot to verify the editor loaded
- Step 4: click on the document body / canvas to focus the editor
- Step 5: fill the document body with the user's requested content
- Step 6: screenshot to verify content was typed
- Step 7: press_key Control+s to save

### PATTERN 2: FILL MULTI-PAGE FORM (Survey, Application, Checkout)
When the user says "Fill out this form" or "Complete this survey":
- Step 1: screenshot to capture current page state
- Step 2: fill each field one by one using the EXACT label text visible on screen
- Step 3: screenshot to verify all fields before submitting
- Step 4: click "Next" or "Continue" to go to next page
- Step 5: wait_for_idle with idleMs:2000, timeout:10000, minWait:3000
- Step 6: screenshot to verify next page loaded
- Step 7: repeat for each page until final submission

### PATTERN 3: SEARCH + EXTRACT INFORMATION
When the user says "Search for [X] and tell me about it":
- Step 1: web_search with the user's query
- Step 2: web_fetch the top result URL to get actual page content
- The AI should then read the fetched content and respond with the information

### PATTERN 4: EMAIL / MESSAGING

## SITE-SPECIFIC INSTRUCTIONS

### Google Docs / Sheets / Slides
- Navigate to docs.google.com/document/create for new docs
- Navigate to docs.google.com/spreadsheets/create for new sheets
- The editor takes 3-5 seconds to fully load — always wait_for_idle with idleMs:3000
- Click directly on the document canvas to focus before typing
- Use Control+s to save
- For shared docs, the URL contains /d/[docID]/edit

### Gmail
- Navigate to mail.google.com
- Click "Compose" button (usually top-left)
- Fill "To" field first, then Subject, then body
- Click "Send" when ready
- Check for "Message sent" confirmation
